# 🏦 Sistema Bancário Simples em Python

🎓 Projeto educacional desenvolvido para praticar os fundamentos de Python, com duas versões evolutivas: uma mais simples (v1) e outra mais estruturada (v2), com gerenciamento de contas e usuários. Criado como parte do bootcamp da [DIO (Digital Innovation One)](https://www.dio.me/).

## 🚀 Funcionalidades

### 🔹 Versão 1.0 — Básica

- 📥 Depósito
- 💸 Saque
- 📄 Extrato de movimentações
- 🧭 Menu interativo no terminal

### 🔸 Versão 2.0 — Com estrutura de dados

- 🧑 Criar novo usuário (nome, data de nascimento, CPF e endereço)
- 🧾 Filtrar usuário por CPF
- 🏦 Criar nova conta (associada a um usuário existente)
- 📋 Listar contas registradas
- 💰 Depósito, saque e extrato por conta
- 🔄 Uso extensivo de **funções** para organização do código

---

## 🧠 Objetivo Educacional

Este sistema foi criado com o intuito de **solidificar os conhecimentos básicos de Python**, como parte prática do **bootcamp da plataforma DIO (Digital Innovation One)**.  
O foco principal está em:

- Utilização de variáveis e estruturas de controle
- Criação e chamada de funções
- Organização de dados em dicionários e listas
- Boas práticas de entrada e saída no console
